## 1. Primary Request and Intent
사용자는 raddit 프로젝트(Reddit 주식 언급량 집계 + $5 미만 페니주식 필터 대시보드)에서 차트 라이브러리 교체(TradingView lightweight-charts v5.2), 페니주식 필터 최적화, 호가잔량비율 표시, 디자인 개선 등을 요청. 모든 작업은 CONTRIBUTING 규칙(이슈→토픽 브랜치→PR→머지커밋)을 준수하여 진행.

## 2. Key Technical Concepts
- **raddit-reddit/**: Python(FastAPI) Reddit RSS 수집 RPC 서비스. Reddit이 Node.js TLS 지문을 차단해서 stdlib urllib로만 통과.
- **raddit-astro/**: Astro 웹 대시보드(메인). SolidJS + TypeScript.
- **lightweight-charts v5.2**: ESM 전용, `addSeries(SeriesDefinition, ...)` 패턴, `autoscaleInfoProvider`로 오버레이 스케일 제외 가능.
- **Yahoo Finance API**: v8/chart(per-ticker, 인증 불필요), spark(batch, 인증 불필요), v7/quote(batch, crumb 인증 필요).
- **ApeWisdom**: Reddit 멘션 데이터 제공(가격 정보 없음). 751개 티커 전체 fetch 가능.
- **한국식 색상 규칙**: 빨강=상승(--up), 파랑=하락(--down).
- **CONTRIBUTING 규칙**: main/dev 직접 push 금지, 무조건 이슈→토픽 브랜치→PR, FF머지 금지(머지커밋만).

## 5. Problem Solving

### 차트 스케일 찌그러짐 (#49, #52)
1. **가설**: 오버레이가 Y축 확장 → `autoscaleInfoProvider: () => null`로 해결 (#50)
2. **추가 발견**: 사용자 수동조정 후에도 찌그러짐 → autoScale-off가 원인 → 레인지 변경 시 `autoScale: true` 재활성화 (#52)
3. **검증**: priceToCoordinate 픽셀 측정으로 수정 전후 비교 (3%→63%)

### 페니주식 필터 최적화 (#51)
1. **분석**: ApeWisdom 751개 전체 fetch, 상위 120개만 가격조회 → 89개 <$5 중 62개(70%)가 랭크 401+에 묻힘
2. **해결**: slice(120) 제거 → spark batch 전수 가격조회 + EQUITY 필터 + FALSE_POSITIVE 가격 연동
3. **효과**: 노출 4건 → 18건, 콜드 로딩 11s→2.5s, Yahoo 요청 ~20배 절감

### 호가잔량비율 표시 (#53)
1. **검증**: Yahoo v7/quote + crumb 배치 호가조회 가능 확인
2. **구현**: attachBidAskBatch (401/403 재시도 포함) + 표 COLS 추가 + 저유동 흐림 처리
3. **E2E**: 17/17 아이템에 buy_ratio_pct 부착
